# 動漫電影版

依使用者要求，取代原「厚塗動漫」畫風。美術方向是新海誠式的動漫電影光影：雨後黃昏、藍紫雲天、暖色窗光、清透髮絲、細輪廓與較自然的臉部比例。人物仍保留既有髮色、服裝、配件與身分。

選單顯示名稱為「動漫電影」。內部 ID 和圖片目錄仍為 `modern-paint`，讓原有的 `mj_art_style` 偏好直接沿用，角色解鎖與操作方式不變。

所有新原畫均使用內建 `image_gen`，未使用 CLI/API 替代生成。精確提示詞、參考圖、生成原稿、切割方式與尺寸／透明度驗證分別記錄於：

- [小翠、月華、阿明、糖糖](portraits-a/README.md)：20 張表情。
- [小春、蘭姐、阿翼](portraits-b/README.md)：15 張表情，包含重畫的阿翼普通表情。
- [標題、雀館、Logo、桌面](ui/README.md)：4 張 UI 圖。

35 張角色皆為 512×512 RGBA，至少 16px 透明留白。標誌為 1400×420，牌桌為 1600×1100；牌桌沿用原本的置中方形幾何，供既有程式套用。兩張背景為 1920×1080。前五種畫風未改動。

原厚塗版來源仍保存在 `../modern-paint`，供歷史比較；該資料夾的整理腳本不代表目前版本。
