# 虛擬台麻館：三風格介面與場景資產

更新：2026-10-20。這份文件記錄已整合的資產、操作方式與檔案檢查；實際瀏覽器流程、遊戲測試及硬體測試結果另由最終驗證記錄提供。

## 共用介面與三種畫風

`artStyle` 同步切換場景、角色立繪與介面配色。90 年代以暖金、綠色牌桌與賽璐璐動畫為主；PC-98 使用較細緻的抖色、靛紫與奶油色；MS-DOS 使用鮮明的藍／青／金色、較粗的像素色塊與方形介面。像素風是美術方向，不宣稱精確符合歷史硬體的色數限制。

標題的左側保留深色空間供文字與選單使用，右側呈現小翠、月華、阿明與蘭姐。空景保留相同雀館、桌面透視與環境配置，沒有角色或介面。PC-98 與 MS-DOS 場景依 90 年代正式背景分別重繪，沒有將概念圖中的介面直接當成可操作畫面。

品牌文字、導覽、輸入框、角色選擇、房間座位、規則、聊天、牌面、手牌、棄牌、倒數與結算皆使用即時 DOM 元件及遊戲資料。場景只是背景；桌上的裝飾性牌牆不代表遊戲狀態。畫面共用同一套操作與遊戲規則，場景切換不改變網路權限。

## 操作方式

| 裝置 | 操作 |
| --- | --- |
| 滑鼠 | 點選頁面按鈕、欄位、角色與手牌；沿用畫面顯示的選牌及出牌流程。 |
| 鍵盤 | Tab／Shift+Tab 或方向鍵移動焦點，Enter／空白啟用按鈕，Esc 返回、關閉對話框或取消選牌；文字欄位保留原生輸入行為。 |
| 標準映射手把 | 十字鍵／左搖桿移動焦點，A 啟用，B 返回／取消；範圍與數值欄位可用左右調整，下拉選單可用左右或 A 切換。 |
| 手把文字輸入 | 在文字欄位按 A 開啟英數與符號螢幕鍵盤，支援空白、退格、清除、大小寫與套用；中文請使用裝置鍵盤，既有中文暱稱會保留。 |
| 觸控 | 點按實際控制元件；選單中長按品牌標誌 1.5 秒可開啟秘技輸入面板。滑動或離開標誌會取消長按。 |

鍵盤與手把選牌都啟用既有手牌控制，不另設繞過選牌確認的出牌快捷鍵。手把相容性取決於瀏覽器 Gamepad API 與標準映射；此文件未宣稱已完成實體手把或觸控裝置測試。

## 隱藏角色阿翼

阿翼可由以下任一條件解鎖：

- 完整比賽進入 `game_over` 時，本機玩家總分大於 0 且為最高分；正分並列第一也算。單局胡牌或觀戰不符合條件。
- 尚未進入房間／對局的選單中輸入 `↑ ↑ ↓ ↓ ← → ← → B A`。可使用鍵盤方向鍵與 B、A，或手把方向與 B、A。
- 觸控使用者在選單長按品牌標誌 1.5 秒，於螢幕秘技面板輸入同一序列。面板也能使用鍵盤與手把操作。

解鎖後阿翼會出現在角色選擇及圖鑑。解鎖記錄存於本機瀏覽器 `localStorage` 的 `mj_unlock_ayi=1`，畫風偏好存於 `mj_art_style`。記錄依來源／瀏覽器儲存空間區分，不會同步到其他裝置；清除網站資料會清除記錄。儲存空間不可用時，當前工作階段仍可切換畫風與解鎖。

阿翼共 15 張表情圖，採用目前 H01-B01 small-v38 VRM 身分及既有 H01 臉部／B01 盔甲渲染參考，保留棕髮、藍眼、銀色盔甲與黑色內搭。模型版本、參考圖沿用理由、生成提示、透明切圖與檢查結果詳見 [阿翼來源說明](../ayi/README.md)。遊戲交付的是插畫，不包含或修改原 VRM 模型。
