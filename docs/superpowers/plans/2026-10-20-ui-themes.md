# Three complete interface themes

**Goal:** Extend the existing persistent art-style selection to the whole interface, retaining the same game controls and rules.

**Design:** Anime90 uses warm gold, green felt, ink-edged rounded panels and cel-like shadows. PC-98 uses indigo/plum windows, cream lettering, double rules and subtle stationary checker dithering. MS-DOS uses VGA blue/cyan, gray beveled controls, square tiles and monospace typography. All three keep readable red/green/blue tile suits, visible selected/discard highlights and clear keyboard focus.

**Architecture:** `artStyle` remains the single preference. App synchronizes it to the document's `data-ui-style` attribute. `src/themes.css` contains complete theme tokens and presentation-only overrides for existing components. Game state, networking and audio behavior remain unchanged.
