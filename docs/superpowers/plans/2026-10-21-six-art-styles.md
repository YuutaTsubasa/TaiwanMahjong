# Six complete visual styles

Approved scope: extend the Taiwan print, four-color Game Boy, and modern painted samples into selectable game themes. Preserve the three existing themes, gameplay, hidden-character unlocking, and input controls.

1. Generate seven characters × five expressions and four UI images for each new style. Each art agent owns one style's assets and provenance only.
2. Test six-style portrait resolution, preference persistence, pixel rendering metadata, and complete runtime image sets.
3. Extend shared style metadata and portrait routing. Adapt settings and the compact selector to six choices.
4. Supply theme tokens, scene paths, decorative overrides, and monochrome tile details. Keep painted artwork smoothly rendered.
5. Verify image dimensions, alpha and Game Boy palette; run tests and production build, then inspect desktop/mobile settings and gameplay.

Style IDs: `taiwan-print`, `gameboy`, `modern-paint`. Portraits: 512 × 512 RGBA; logo: 1400 × 420; table: 1600 × 1100 with the same approved geometry. Game Boy art uses only #0f380f, #306230, #8bac0f, #9bbc0f and transparent pixels.

No commit, push, deployment, or gameplay changes are part of this task.
